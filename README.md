# NLP SpaCy Program

This is a simple Python program that uses the spaCy library to perform various Natural Language Processing (NLP) operations on a given text.

## Features

*   Tokenization
*   Linguistic annotation
*   Lemmatization
*   Sentence detection
*   Part-of-speech (POS) tagging
*   Named Entity Recognition (NER)
*   Stop words removal
*   Dependency parsing

## Installation

1.  **Clone the repository or download the files.**
2.  **Install the required libraries:**
    ```bash
    pip install -r requirements.txt
    ```
3.  **Download the spaCy English model:**
    ```bash
    python -m spacy download en_core_web_sm
    ```

## Usage

1.  **Run the script:**
    ```bash
    python nlp_spaCy_program.py
    ```
2.  **Enter your text when prompted.**
3.  **Choose an NLP operation from the menu.**
